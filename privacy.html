Privacy Policy

Effective October 16, 2026

Gary Calendar is a private tool operated by Jorgensen Holdings for its own use. It connects only to the Jorgensen Holdings Google account (jorgensenholdings@gmail.com).

What it accesses

With the account owner's permission, it reads and creates events on the Jorgensen Holdings Google Calendar and reads and labels messages in the Jorgensen Holdings Gmail inbox, in order to schedule rental property showings and respond to showing requests.

How the data is used

Data is used only to operate Jorgensen Holdings' own scheduling. It is not sold, shared with third parties, or used for advertising. Access tokens are stored encrypted on Jorgensen Holdings' own computer.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the Google Account's Third-party connections page.
